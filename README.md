# 企业岗位经验 Skill 生成平台

> 让业务人员无需代码，用自然语言把岗位经验沉淀为**可执行、可复用、可溯源**的 AI 员工能力（Skill）。

**核心闭环**：`起名 + 自然语言描述 → Skill 自动生成（7 要素）→ 配置编辑发布 → 上传数据执行 → 输出标准分析报告`

---

## ✨ 功能特性

- **一句话生成 Skill**：自然语言输入 → LLM 按 7 要素（名称 / 描述 / 使用场景 / 输入数据定义 / 分析流程 / Agent Prompt / 输出模板）结构化生成，含 schema 校验与失败自动重试（≤3 次）；信息不足时自动反问澄清
- **创建时命名 + 自动防重名**：创建必须给 Skill 起名（优先于模型生成的名字）；资产库支持随时改名；创建或改名时若与已有资产重名，自动追加序号（2）（3）……
- **资产管理**：资产库列表 + 关键词搜索 + 状态筛选（草稿 / 已发布 / 已下线）+ 改名 + 删除（二次确认，级联清理关联报告）+ 版本号 + 执行次数统计
- **生命周期管理**：草稿 → 发布 V1.0 → 下线 → 重新发布；未发布的 Skill 禁止执行（前后端双重校验）
- **执行引擎（混合调度）**：确定性计算（汇总 / 均值 / 极值 / 环比 / 达成率 / Top 分类，100% 可复现）与 LLM 推理（归因 / 建议）混合调度——**只让 AI 做"经验判断"，不让 AI 算数**
- **数据溯源**：报告每个结论标注来源（`[数据计算]` / `[AI 分析]`），"事实"与"AI 推断"一目了然
- **过程可视化**：执行时逐步展示 解析 → 校验 → 计算 → 推理 → 组装 的每一步产出
- **Skill 效果对比（Demo 专属）**：载入示例数据执行时，同时生成「使用 Skill / 不使用 Skill」两份报告，并由 AI 完成价值对比
- **报告闭环**：Markdown 报告（含表格）、复制 / 下载 .md、👍👎纠错反馈（沉淀为 Skill 优化依据）
- **模型可替换**：LLM 调用集中在单一服务层，换通义 / GLM / GPT 只改一处
- **安全合规**：API Key 仅存本机（已加入 .gitignore）；报告渲染全程 HTML 转义防 XSS
- **8 个内置推荐场景**：直播复盘 / 电商运营 / 销售经营 / 用户增长 / 零售门店 / 客服质检 / 招聘人才 / 内容运营，点击即用

## 🚀 快速开始

**环境要求**：仅需 Node.js ≥ 18，**零 npm 依赖**，无需 `npm install`。

```bash
node server/server.js
```

打开浏览器访问 **http://localhost:3000**。

> ⚠️ 平台已彻底移除演示模式，**必须先配置 API Key 才能使用**：
> 首次访问点右上角 **⚙ LLM 设置**，选择模型版本并粘贴 Key → 保存并生效。
> 之后即可完整跑通：首页填名称 + 描述 → 生成 → 保存草稿 → 发布 → 上传数据执行 → 查看报告。

## ⚙️ LLM 接入配置

### 配置方式（任选其一）

| 方式 | 操作 | 适用场景 |
| --- | --- | --- |
| **页面配置**（推荐） | 右上角「LLM 设置」弹窗：选模型 + 粘贴 Key → 保存 | 日常使用 |
| **环境变量** | PowerShell：`$env:DEEPSEEK_API_KEY="sk-xxx"; node server/server.js` | 服务器部署（Key 不入库、不进配置文件） |

> Key 仅保存在本机 `server/data/config.json`（该文件已被 `.gitignore` 排除，不会进版本库），
> 只用于直接调用 LLM 接口，不上传任何第三方服务器。

### 模型版本选择

在「LLM 设置」弹窗中选择具体模型版本，顶栏徽章与首页会动态展示当前模型：

| 界面选项 | 实际接口模型名 | 说明 |
| --- | --- | --- |
| v4pro | `deepseek-v4-pro` | 旗舰模型（最强能力） |
| flash | `deepseek-v4-flash` | 快速模型（响应更快） |
| chat | `deepseek-chat` | 通用对话模型（默认） |

映射关系在 `server/config.js` 的 `llm.modelOptions` 中配置（`id` 为界面标识，`apiModel` 为接口模型名），
接口地址与超时也可通过 `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL` 环境变量覆盖。

## 📖 使用流程

1. **起名 + 描述需求**：首页填 Skill 名称和一句需求描述（可点推荐场景卡片快速填充）
2. **生成草案**：LLM 按 7 要素生成结构化草案（逐条动画展示，可重新生成）；生成中切换页面不会中断，回首页自动恢复
3. **编辑并发布**：7 要素在线编辑 → 保存草稿（自动防重名）→ 发布 V1.0
4. **上传数据执行**：上传 CSV / 粘贴表格文本；`Demo-` 前缀的演示 Skill 还支持「载入示例数据」并启用效果对比
5. **查看报告**：Markdown 报告（可复制 / 下载）、切换对比页签、👍👎纠错反馈

## 🧠 执行引擎设计（技术核心）

```
上传数据
   │
   ▼
① 数据解析   程序解析 CSV/粘贴文本（自动识别 GBK/UTF-8、逗号/制表符分隔）
   ▼
② 数据校验   对照 Skill 的"输入数据定义"检查字段，缺失时明确列出
   ▼
③ 指标计算   纯 JS 确定性计算：汇总/均值/极值/环比/达成率/Top分类 —— 结果 100% 可复现
   ▼
④ AI 推理    把计算结果交给 LLM 生成归因与建议 —— 只做"经验判断"，不做算术
   ▼
⑤ 报告组装   按输出模板组装，章节缺失自动补齐；标注每个结论的来源
```

**设计要点**：

- **确定性计算与 LLM 推理分离**：数值全部由程序计算，结果可复现、可溯源；归因、结论、建议等"需要经验判断"的步骤才交给 LLM
- **数据溯源**：每个结论标注 `[数据计算]`（程序算的，可信）或 `[AI 分析]`（模型推的，需复核）
- **友好降级**：LLM 调用超时 / 失败时给出明确中文错误提示，页面不白屏；报告章节缺失自动补齐并标注
- **效果对比**：同一份数据分别用「使用 Skill（岗位人设 + 模板 + 确定性计算）」与「裸调通用 LLM」生成报告，AI 对比阐述 Skill 的结构化提升与业务价值

## ❓ 常见问题

**Q1：没有 API Key 能使用吗？**
不能。平台已彻底移除演示模式，必须先在右上角「LLM 设置」配置真实 API Key 与模型版本（v4pro / flash / chat）后才能生成 Skill 与执行分析。

**Q2：创建时名称会和已有资产重名吗？**
不会。创建或改名时若与其他资产重名，后端会自动追加序号（2）（3）……，并在提示中告知。

**Q3：为什么资产库里只有一个 Demo？**
平台仅保留「Demo-抖音直播运营复盘」一个演示资产用于测试。新建的 Skill 不再带 Demo- 前缀（推荐场景快速填充时也会自动去掉前缀）。

**Q4："载入示例数据"执行时和普通执行有什么区别？**
仅 Demo 前缀的演示 Skill 显示「载入示例数据」入口。载入后启用 **Skill 效果对比**：同时生成「使用当前 Skill」（岗位专家人设 + 输出模板 + 确定性计算）与「不使用任何 Skill」（仅基础 LLM 能力自由分析）两份报告，再由 AI 完成差异化与价值对比；报告页可切换三个页签查看，下载 .md 为合并的完整对比文档。普通上传 / 粘贴数据执行保持单报告模式。

**Q5：Excel（.xlsx）文件能上传吗？**
支持 CSV 与粘贴表格文本。Excel 请先"另存为 CSV"再上传；GBK 编码的 CSV（国内 Excel 常见）已支持自动识别。

**Q6：接口报 401 / 402 怎么办？**
401 表示 API Key 无效（检查是否复制完整、是否多复制空格）；402 表示余额不足。

**Q7：为什么报告里的数字和 LLM 文字描述不一样？**
以"二、核心指标总览"表格为准——那是程序确定性计算的，可溯源到源数据。LLM 推理章节标注了 `[AI 分析]`，需要人工复核，这正是平台的"可信设计"。

**Q8：想接入其他模型（通义 / GLM / GPT）？**
改 `server/llmService.js` 的 `callDeepSeek` 一处即可（接口均为 OpenAI 兼容格式），Skill 生成与执行引擎完全不用动；模型名映射在 `server/config.js` 的 `llm.modelOptions` 中调整。
